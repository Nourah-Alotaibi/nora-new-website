04 / Explore XAI · SHAP

Why this turn?

Pause this board and unpack the brain’s preferred next move. Which signals tip the balance?

Exact SHAP values for the preferred move versus its runner-up, relative to an all-zero sensor reference. Green supports the preferred move; muted green supports the alternative. This explains the network’s scores; curiosity may still choose a random action.

What does the reference mean?

We switch each sensor between its current value and zero, evaluate all 2,048 combinations, and average its contribution across every order of adding sensors. Zero means all signals off, not a typical board. Some combinations are not valid game states, so these are model attributions, not causal explanations of the world.

How the experiment works · references

The contribution / beyond a scoreboard

What about the turn it didn’t take?

With “what if?” replay, each real move also creates two one-step branches in a copy of the game. The outcomes of those unchosen moves join replay memory, while the real board stays untouched.

This is a model-based extension to Double DQN, inspired by Dyna-style planning. It uses known game rules and extra simulator queries—not magic foresight. Turn it off to compare with standard replay.

A little honesty goes a long way

Learning is messier than a high score.

Weights really update through backpropagation and Adam. A target network and replay buffer help stabilize learning. The optional distance hint is designed into the reward; the agent is not discovering everything unaided.

Longer snakes can trap themselves. The small sensor view hides parts of the world, and more neurons or a faster learning rate can make a run worse. These limitations are part of the experiment.
